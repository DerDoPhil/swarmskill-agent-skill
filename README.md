# SwarmSkill — Agent Skill (usage guide)

Agent-Skills-kompatible Nutzungsanleitung für **SwarmSkill**, das ERC-8257
Schwarm-Trading-Tool (Tool ID 25, Ethereum Mainnet Registry
`0x265BB2DBFC0A8165C9A1941Eb1372F349baD2cf1`).

- 📄 Skill-Datei: [`SKILL.md`](./SKILL.md) — kompatibel mit allen
  [Agent-Skills](https://agentskills.io)-fähigen Agents (Claude Code, Codex,
  VS Code, …)
- 🌐 Live-API: https://swarm-skill.vercel.app
- 📜 Kanonisches Manifest: https://swarm-skill.vercel.app/.well-known/erc8257-manifest.json
- 🔍 Gelistet im [Agent Tool Index](https://agenttoolindex.xyz)

Installation in skills-kompatiblen Agents:

```bash
npx skills add DerDoPhil/swarmskill-agent-skill
```

> Dieses Repo enthält **nur die Nutzungsanleitung** — der SwarmSkill-Dienst
> selbst ist proprietär und läuft ausschließlich unter swarm-skill.vercel.app.
> Nutzen erlaubt, kopieren/re-hosten nicht.
